Position size calculator

Decide how much you are willing to lose first. This works out the size that keeps a stop-out inside that amount, rounded down, with fees included.

How the maths works

  • Stocks: size = (risk − commissions) ÷ (|entry − stop| + per-share costs), rounded down.
  • Futures: tick value = contract multiplier × tick size. Risk per contract = stop distance in ticks × tick value + round-trip fees.
  • Forex: pip value per unit = pip size × quote-to-account rate. Units = risk ÷ (stop pips × pip value per unit).
  • Crypto: quantity = risk ÷ (|entry − stop| + fees per unit). Margin = position value ÷ leverage.
  • Options: long options risk the premium × 100 per contract. A credit spread risks (width − credit) × 100 per contract.

Size is always rounded down so the result never exceeds your risk limit. Exchange specifications such as tick values should be confirmed against your broker or the exchange.
